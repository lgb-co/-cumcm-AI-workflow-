## 主要问题

### 贪心解没有最优性说明

题目要的是“最优种植方案”，README 也写明了改用贪心是因为线性规划太复杂。贪心本身没问题，但代码里既没有给出解的误差范围，也没有拿整数规划或上界做一次对照，无从判断离最优有多远。补一个整数规划或松弛上界的对照就能把这条补上。

### 附件到 JSON 的数据链缺了一段

脚本读的是仓库里的 JSON，`data1_1`、`data2` 这些文件在 `a1/2023` 等目录下。但从赛题附件 xlsx 生成这些 JSON 的脚本不在仓库里，`数据处理文件/` 只有结果，没有生成过程。别人拿到原始附件还是复现不了，需要把预处理脚本补进来，或者在脚本里直接读附件。

### 运行说明和依赖没写

仓库只写了方法摘要，没有 requirements，也没有说清四个脚本的顺序和运行目录。第一次用的人得自己试出“在各自目录里跑”这件事，还要自己发现需要 numpy 和 openpyxl。

### 一些小问题

`c/script.py` 运行时会打印大量 defaultdict 中间状态，正式跑的时候建议去掉或改到日志里。`limitminarea = {1:1, 2:1, 3:1, 4:1, 5:0.1, 6:0.1}` 这类阈值没有注释来源，换题容易出错。

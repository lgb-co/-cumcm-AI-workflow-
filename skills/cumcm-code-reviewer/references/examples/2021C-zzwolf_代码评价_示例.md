## 【8 点验证链】

**1 是否实现论文模型：⚠️**
证据：四问均有脚本，PCA/GA 与思路说明一致；第1问实现"9 维指标+PCA 加权打分"。
说明：模型**有落地**；但"论文"仅为思路 md，缺完整论文细节（如目标函数权重来源、Q4 联合 vs 顺序的口径），无法做逐公式对照。

**2 算法实现是否正确：⚠️**
证据：GA 类含 func/constrain/get_fitness_and_select/crossover_and_mutate/evolution/fit（第2~4问.py L10-89）；第1问用 `sklearn.decomposition.PCA(svd_solver='full')`。
说明：GA 骨架（适应度→选择→交叉变异→进化）正确；但 `constrain` 与 `func` 的具体目标/约束是否与题意一致需运行+对公式核验；Q1 用**全量主成分按方差加权**作为得分，属自定义做法，是否合理需论文论证（潜在"方法可用性"问题）。

**3 参数是否正确：⚠️**
证据：Q1 用 A/B/C 转化率 0.6/0.66/0.72 换算"可生产产品数"（第1问.py L17-27）；GA 超参（cross_rate=0.8, mutation=0.003）在 `__init__` 默认值。
说明：转化率数值须与 2021C 题目附录核对（疑为 1/0.6、1/0.66、1/0.72 的产品换算口径）；魔法数（0.6/0.66/0.72、240 周、6000 上限）未集中注释来源；无随机种子。

**4 数据处理是否正确：⚠️**
证据：第1问.py 读 `附件1 近5年402家供应商的相关数据.xlsx` 两个 sheet，按列切片 data_order=data1[:,2:]、data_supply=data2[:,2:]。
说明：读取方式合理；但 Q1 用 `data_order2[k]!=0` 切片算变异系数/偏移，**空切片会使 std/mean 出错或除零**（未防护）；缺失值/异常未显式处理；第2~4问的数据衔接文件不直观。

**5 有无隐藏错误：⚠️**

说明：未发现确定性崩溃证据，但上述均为潜在隐藏错误/维护隐患；需真跑 + lint 确认。

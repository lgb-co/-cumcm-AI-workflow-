# 检索与引用规范

本文件规定联网检索怎么搜、结果怎么分级、出处怎么写。方案里每一条关键结论（模型适用性、参数取值、数据口径、经验规律）都必须挂到来源表里的某一条。

## 一、来源分级

| 级别 | 范围 | 用法 |
|---|---|---|
| **A** | 同行评审论文（期刊/会议/学位论文）、官方统计年鉴与公报、国家标准/行业标准、国际标准（ISO/IEC/ASTM）、官方赛题与评阅要点 | 可直接作为方法依据与数据依据；结论优先引用 A 级 |
| **B** | 权威机构报告（世行/联合国/OECD/IMF/行业协会）、经典教材与专著、官方文档（如算法原始文档） | 可作方法依据；涉及具体数值时需与 A 级或题给数据交叉验证 |
| **C** | 高质量 GitHub 实现、技术博客、教程 | 只作实现参考与检索线索，不得作为方法唯一依据，不得直接引用其结论数值 |
| **禁用** | AI 洗稿站、文库、无署名聚合页、内容农场、来源不明的“某年优秀论文”转载 | 不作为依据；若只找到此类内容，写“未找到权威来源”并说明处理方法 |

**国际来源加权**：同类结论若同时有中文与英文来源，优先引用国际同行的原始文献或高被引综述（更强的可复现性与可验证性）；中文文献用于国内口径、国标与赛题语境。

## 二、国际学术来源清单（含本机实测可达性，2026-09-10）

> 可达性是在本机实测的结论，网络策略会变化；使用时先按第 3 节的方式探测一次，再决定通道。

### 2.1 元数据与发现 API（首选，稳定且可脚本化）

| 来源 | 入口 | 用途 | 实测 |
|---|---|---|---|
| OpenAlex | `api.openalex.org/works?search=...` | 论文检索与元数据（标题/作者/年/DOI/期刊）核验 | 可达 |
| Crossref | `api.crossref.org/works?query=...`、`search.crossref.org` | DOI 注册机构元数据，权威且覆盖全 | 可达 |
| arXiv API | `export.arxiv.org/api/query?search_query=...` | 预印本（数理、优化、机器学习、统计） | 可达 |
| Semantic Scholar | `api.semanticscholar.org/graph/v1/...`（站点 `semanticscholar.org` 可达） | 引用关系、被引次数、相关论文推荐 | API 返回 403（需 key），站点可达 |
| DOAJ | `doaj.org/api/search/articles/...` | 开放获取期刊论文全文线索 | 可达 |
| Europe PMC / PubMed E-utilities | `ebi.ac.uk/europepmc/webservices/rest/search`、`eutils.ncbi.nlm.nih.gov` | 生物医学与统计方法文献 | 可达 |
| DataCite | `api.datacite.org/dois` | 数据集 DOI 元数据 | 可达 |
| RePEc / BASE / CORE | `ideas.repec.org`、`base-search.net`（可达）、`core.ac.uk`（被拒） | 经济管理文献、机构库聚合检索 | RePEc、BASE 可达；CORE 需换通道 |

**用法**：先在这些 API 里检索候选文献并核验“标题—作者—年份—DOI—期刊”五项一致，再决定是否访问全文；引用时直接用核验过的元数据，避免抄错。

**限流与冗余**：OpenAlex 的匿名检索会被服务端临时暂停（实测返回 503「Anonymous search is paused while the search cluster recovers」，2026-09-10），此时设置环境变量 `OPENALEX_API_KEY`（免费申请）即可恢复；Crossref、arXiv、DOAJ 不受影响。因此**至少用两个引擎交叉检索**，任一引擎失败都能继续，且同一篇文献最好在两个引擎里都能查到。

**一键检索**：`scripts/search_literature.py --query "<英文方法名>" --query "<中文关键词>" --from-year 2020 --out <交付目录>/data/国际文献来源表.md` 会并发查询四个引擎、按 DOI 与标题去重，输出可直接使用的来源表（含待填的“支撑结论”列）。

### 2.2 出版商与全文站点

| 可达（含需指定 UA/curl 的情形） | 实测不可达（多为反爬拦截） |
|---|---|
| Springer Link、Nature、IOPscience、Frontiers、De Gruyter、Project Euclid、JSTOR、IEEE Xplore（需 `curl` + 浏览器 UA） | ScienceDirect（400）、Wiley、Taylor & Francis、SAGE、ACM DL、MDPI（403）、Science、PNAS、SIAM、INFORMS、Emerald |

**被拦截时的替代路径**（按序尝试）：① 用 OpenAlex/Crossref 拿到 DOI 与摘要后引用元数据，并在数据/来源表中注明“出版商页面受网络策略限制，元数据已核验”；② 找该论文的 arXiv/机构库/作者主页开放版本（arXiv、RePEc、BASE、DOAJ、Europe PMC 均可达）；③ 若论文确实关键且只能拿到摘要，正文中只引用其“方法与结论”，不引用无法核实的数值。

### 2.3 标准、规范与官方文档

| 来源 | 实测 |
|---|---|
| 国家标准全文公开系统 `openstd.samr.gov.cn`（国标 GB/GB-T 全文） | 可达，但**必须用 `curl.exe`**（PowerShell 内置请求会报 SSL 失败） |
| NIST（美国国家标准与技术研究院，含手册、数据集、不确定度指南） | 可达 |
| ISO、IEC、ASTM | 站点被拒；可用其标准编号在 Crossref/OpenAlex 或各国标准馆镜像核验编号与年份，正文按标准编号引用 |
| 官方赛题与评阅要点（mcm.edu.cn） | 可达 |

### 2.4 检索入口

Google Scholar、Bing、DuckDuckGo（`html.duckduckgo.com/html/?q=`）、百度学术均可作为入口；用 `site:` 限定（如 `site:arxiv.org`、`site:github.com`、`site:openstd.samr.gov.cn`）。检索入口只用于发现线索，最终依据必须回到 2.1—2.3 的具体来源。

## 三、抓取通道与探测

1. **优先 `curl.exe`**：本机实测中，`doi.org`（DOI 解析到出版商）与 `openstd.samr.gov.cn` 用 PowerShell 内置请求会误报失败，换 `curl.exe -sL` + 浏览器 UA 即正常。抓取前先探测一次。
2. **UA 与限速**：统一带浏览器 User-Agent；同一站点 ≥1 秒/请求，批量 ≤200 请求/次；429/403 先降速重试一次，再换通道或换源。
3. **不改写来源**：只摘录与引用，不把外文内容改写成“自己的结论”却不标注；不下载版权受限的整本教材。
4. **探测记录**：每道题的来源表要记录访问日期；对不可达但已核验元数据的来源，注明“元数据核验，正文未能访问”。

## 四、检索广度与双线检索（默认深搜档）

对每一问都要跑“中文线 + 国际线”两条检索，不能只搜中文资料：

| 线 | 检索对象 | 最低要求 |
|---|---|---|
| 中文线 | 赛题专属解读、国内期刊与学位论文、国家标准、统计局与行业口径 | ≥4 个可用来源，含至少 1 项国标/官方口径 |
| 国际线 | 英文原始文献、综述、benchmark 与竞赛/案例研究 | ≥6 个可用来源，含 ≥2 篇方法原始文献（提出该方法的论文）与 ≥3 篇近 5 年应用或综述 |

- **总量**：默认每题 ≥15 个可用来源（深搜档）。
- **覆盖**：候选路线中的每一个方法都要有至少 1 篇 A 级来源支撑其“适用条件”；不能出现“只用了一个博客就选定模型”的情况。
- **优先级顺序**：方法原始文献 → 近 5 年综述/对比研究 → 同题应用案例 → 实现参考（C 级）。
- **英文检索式模板**：`"<问题英文描述>" + "<方法英文名>" + (review OR survey OR comparison OR benchmark)`；算法原始出处用 `<方法名> original paper <年份>`；应用类用 `<方法英文名> application <领域英文> case study`。
- 常用方法英文名：层次分析法 AHP、熵权法 entropy weight、TOPSIS、灰色关联 grey relational analysis、灰色预测 GM(1,1)、主成分分析 PCA、因子分析 factor analysis、聚类 clustering / K-means、判别分析 discriminant analysis、多元回归 multiple regression、岭回归 ridge regression、LASSO、ARIMA、指数平滑 exponential smoothing、卡尔曼滤波 Kalman filter、马尔可夫链 Markov chain、隐马尔可夫 HMM、蒙特卡洛 Monte Carlo simulation、元胞自动机 cellular automata、排队论 queueing theory、线性/整数规划 linear/integer programming、多目标优化 multi-objective optimization、NSGA-II、粒子群 particle swarm optimization、遗传算法 genetic algorithm、模拟退火 simulated annealing、蚁群 ant colony optimization、差分进化 differential evolution、有限元 finite element method、微分方程 ODE/PDE model、图论 graph theory、最短路 shortest path、网络流 network flow、支持向量机 SVM、随机森林 random forest、梯度提升 gradient boosting、LSTM、DEA、贝叶斯推断 Bayesian inference、序贯概率比检验 SPRT、马尔可夫决策过程 MDP、鲁棒优化 robust optimization。

## 五、“更合适的模型”如何判定与采纳

本地选型库只是先验。国际检索若发现更贴合的模型或算法，应当采用，并按下列规则留痕：

**判据（满足 2 条以上即可列为更优候选）**
1. **假设更弱或更贴题**：所需假设比当前候选更少、更符合题目实际（例如允许异方差、允许次品率未知）。
2. **可检验性更强**：能给出明确的检验、误差界或收敛性结论。
3. **性能更优且有对比**：在同类问题上有 benchmark 或对比实验支持其精度/成本优势。
4. **被同行广泛采用**：高被引综述或教科书中被列为该类问题的标准方法。
5. **与本题目约束兼容**：不违反题面红线（时间、数据可得性、交付格式）。

**必须写进方案的内容**（缺一不可）
- 候选方法名称、来源（尾注编号）、该方法的关键假设与适用条件；
- 与原候选（含本地语料里同题常见做法）的逐项对比；
- 采纳理由与被替换掉的做法；
- 若最终**未**采纳国际文献里的方法，也要写一句为什么（例如数据量不足、无法检验、超出题目要求）。

**最低检索动作**：对每个主选模型，必须检索一次“该方法 vs 同类方法”的对比或综述类文献，避免只看到支持性证据；对存在争议的方法（如小样本预测、启发式优化）必须引用至少一篇批评或局限讨论。

## 六、证据登记（每条来源一行）

| 字段 | 说明 |
|---|---|
| 编号 | S01、S02…与尾注编号一致 |
| 标题 | 原文标题，不加改写 |
| 作者/机构 | 多位作者写前三位 + 等 |
| 年份 | 发表或发布年份 |
| 类型 | 期刊/会议/学位论文/标准/报告/数据集/代码仓库/网页 |
| 级别 | A/B/C |
| 语言 | 中文/英文/其他 |
| URL/DOI | 可打开的链接，优先 DOI |
| 访问日期 | 抓取当日日期 |
| 可达状态 | 已访问全文 / 仅元数据核验（说明通道） |
| 支撑结论 | 这一条支撑方案里的哪句话（对应章节或公式编号） |

## 七、GB/T 7714 尾注模板

正文用上标编号（Markdown 写作时用 `[^1]`，导出 Word 时转成尾注），文末按编号顺序列出：

- 期刊：`作者. 篇名[J]. 刊名, 年, 卷(期): 起止页码.`
- 会议：`作者. 篇名[C]//论文集名. 出版地: 出版者, 年: 页码.`
- 学位论文：`作者. 题名[D]. 城市: 学校, 年.`
- 专著：`作者. 书名[M]. 版本. 出版地: 出版者, 年: 页码.`
- 标准：`标准编号 标准名称[S]. 出版地: 出版者, 年.`
- 报告：`作者. 报告名[R]. 出版地: 出版者, 年.`
- 电子资源：`作者. 题名[EB/OL]. (发布日期)[访问日期]. URL.`
- 数据集：`发布机构. 数据集名称[DS/OL]. (发布年份)[访问日期]. URL.`

英文文献同结构书写，作者姓前名后（Zhang San 写 `ZHANG S`），英文期刊名统一缩写或不缩写但全文一致，并在可获取时附 `DOI:`。

## 八、引用纪律

- **编号连续**：尾注从 1 开始连续编号，正文引用与文末条目一一对应；不得出现无正文引用的条目，也不得引用不存在的编号。
- **实测可打开**：写进方案前逐条打开核对标题/作者/年份与引用内容一致；仅能核验元数据的要标注清楚，不得写成“已阅读全文”。
- **就近引用**：公式、参数、数据分别就近挂来源，不要只在文末丢一堆链接。
- **自证与引用分离**：基于赛题与数据的推导属于“本文工作”，不得伪装成引用；引用只用于外部依据。
- **国际来源不得装饰化**：禁止为了“显得国际化”而堆砌与结论无关的英文文献；每条国际来源都要说明它支撑了哪条判断。

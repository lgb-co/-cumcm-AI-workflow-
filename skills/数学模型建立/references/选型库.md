# 选型库（问题类型 → 候选模型 → 检验 → 坑）

**定位：这是先验候选池，不是白名单。** 用它快速生成候选模型池，最终以“题意适配 + 数据可得 + 可检验”为准；联网检索若发现更合适的模型或算法，采用它并写明取舍理由与出处。

先验排序来自 `选型库_语料统计.md`（243 篇获奖论文档案，177 篇有题号且检出方法关键词）：全局高频为回归 37.3%、规划模型 31.1%、多目标 28.8%、最小二乘 26.6%、微分方程 20.9%、仿真 20.9%、聚类 20.3%、遗传算法 19.8%、灰色 17.5%、模糊 15.8%。分题看，A 题偏机理（微分方程 31 篇居首），B 题偏规划与网络（规划 27、最短路 16、图论 12），C 题偏数据驱动（回归 16、聚类 13、DEA 10、LSTM 6）。

## 一、先判题型

读题后先归类，再取候选：

| 题型 | 识别信号 |
|---|---|
| 机理/物理建模 | 有物理量、守恒律、几何关系、动力学过程 |
| 评价与排序 | 要求评价、排序、择优、等级划分、综合得分 |
| 预测 | 要求预测未来、趋势、峰值、下一时刻状态 |
| 优化与规划 | 要求最优方案、最小成本、最大收益、调度、分配 |
| 统计推断 | 要求判断是否显著、找影响因素、建立回归方程 |
| 分类与聚类 | 要求分几类、识别、判别、降维 |
| 图论与网络 | 有节点—边结构、路径、流量、匹配 |
| 仿真与随机 | 含随机性、排队、概率事件、复杂系统 |
| 时间序列与状态转移 | 单序列按时间展开、状态迁移 |
| 决策与博弈 | 多方主体、策略互相影响 |

## 二、各类候选与要点

### 1. 机理/物理建模（A 题主力）
- **候选**：微分/差分方程、守恒方程、力学与几何约束、有限元或离散化数值解、参数辨识；光学类可用光线追迹与蒙特卡洛光线追踪。
- **语料信号**：A 题微分方程 31 篇、牛顿法 17 篇；2022A 微分方程 4 + 牛顿 4；2018A 微分方程 3 + 有限元 1。
- **适用条件**：题面给出物理机理或几何关系，能从第一原理写方程。
- **必备检验**：量纲齐次、平衡点与稳定性、步长/网格收敛性、参数可辨识性、与题给实测残差、极端参数行为。
- **常见坑**：把经验拟合当机理；缺无量纲化导致数值病态；用“文献参数”却不给区间与灵敏度。

### 2. 评价与排序
- **候选**：AHP、熵权/CRITIC、TOPSIS、灰色关联、模糊综合评价、主成分或因子降维后评价、DEA。
- **语料信号**：灰色 33 篇、模糊 29 篇；2021C 出现 TOPSIS 2 + 熵权 2。
- **适用条件**：指标可量化且方向明确；样本数远小于指标数时慎用客观赋权。
- **必备检验**：AHP 一致性 CR<0.1；主客观权重两套对比；权重 ±10% 排序是否翻转；与等权或单一指标基线对比。
- **常见坑**：指标方向未统一就套 TOPSIS；熵权法里同一指标既当投入又当产出；排序结论不给稳定性证据。

### 3. 预测
- **候选**：多元/逐步回归、ARIMA 与季节分解、灰色 GM(1,1) 与 Verhulst、指数平滑、LSTM/随机森林/梯度提升（样本充足时）、组合预测。
- **语料信号**：回归 67 篇居首；2023C 回归 6 + ARIMA 4 + LSTM 4；2025C 随机森林 2。
- **适用条件**：样本量匹配方法（灰色宜小样本短序列，机器学习需数百以上）；外推范围有限。
- **必备检验**：RMSE/MAE/MAPE、残差白噪声、留出或滚动交叉验证、灰色模型级比与后验差比、外推风险说明。
- **常见坑**：小样本硬上神经网络；用拟合优度代替预测误差；不给预测区间。

### 4. 优化与规划
- **候选**：线性/整数/0-1 规划、非线性规划、多目标（加权、ε-约束、NSGA-II 与帕累托前沿）、动态规划、网络流与最短路、选址与调度；遗传、粒子群、模拟退火、蚁群、差分进化作为大规模或非凸问题求解器。
- **语料信号**：规划模型 56 篇、多目标 51 篇（B 题规划 27 + 多目标 24）；2024C 规划 6。
- **适用条件**：目标与约束可数学化；先判线性/凸性，能精确求解就不用启发式。
- **必备检验**：约束满足与可行性、最优性或 gap、参数灵敏度、多起点/多次运行稳定性、与贪心等基线对比。
- **常见坑**：启发式参数拍脑袋且只跑一次；多目标直接加权却不做权重敏感性；目标量纲不一致未归一化。

### 5. 统计推断与回归
- **候选**：多元线性回归、岭回归与 LASSO、广义线性模型、方差分析、假设检验（含非参数）、典型相关、贝叶斯方法。
- **语料信号**：最小二乘 47 篇、回归 67 篇；2024B 贝叶斯 2。
- **适用条件**：样本独立、误差结构可描述；变量数与样本量接近时先做变量选择或正则化。
- **必备检验**：VIF 多重共线性、异方差、DW 自相关、显著性、AIC/BIC 与变量选择稳定性、交叉验证。
- **常见坑**：把相关当因果；共线性下解释系数正负；忽略分层导致辛普森悖论。

### 6. 分类与聚类
- **候选**：K-means、层次聚类、DBSCAN、高斯混合、主成分/因子降维、判别分析、逻辑回归、决策树与集成（随机森林、LightGBM）、SVM。
- **语料信号**：聚类 36 篇；2022C 聚类 5 + 决策树 5 + 主成分 4；2025C 支持向量 2、随机森林 2。
- **适用条件**：有明确距离或相似性定义；聚类前必须标准化并说明距离选择。
- **必备检验**：聚类数选择（肘部/轮廓系数/CH 指数）、重采样稳定性、分类用混淆矩阵与交叉验证、降维累计方差贡献。
- **常见坑**：不标准化直接欧氏距离；用聚类标签再做监督学习却不说明；主成分解释脱离原量纲。

### 7. 图论与网络
- **候选**：最短路（Dijkstra/Floyd/Bellman-Ford）、最小生成树、最大流最小割、匹配与指派、旅行商及变体、网络中心性。
- **语料信号**：B 题最短路 16、图论 12；2018B 动态规划 2。
- **适用条件**：题面天然是图结构（道路、管道、通信、供应链、关系网）。
- **必备检验**：连通性、解可行性、复杂度与规模上限、小规模枚举对照、权重非负等前提检查。
- **常见坑**：负权仍用 Dijkstra；把有向当无向；规模扩大后不说明复杂度。

### 8. 仿真与随机模型
- **候选**：蒙特卡洛、元胞自动机、排队论、马尔可夫链、离散事件仿真、系统动力学。
- **语料信号**：仿真 38 篇；2023A 蒙特卡洛 4、2024C 蒙特卡洛 3、2021A 蒙特卡洛 2。
- **适用条件**：解析求解不可行或系统含随机性；必须给出随机机制与参数分布依据。
- **必备检验**：收敛性（重复次数与标准误）、置信区间、随机种子记录、与解析解或极限情形对照。
- **常见坑**：只跑一次就下结论；分布参数无依据；忽略方差缩减。

### 9. 时间序列与状态转移
- **候选**：ARIMA/SARIMA、指数平滑、GARCH、马尔可夫链与隐马尔可夫、状态空间与卡尔曼滤波、Prophet。
- **语料信号**：时间序列 23 篇；2025B 卡尔曼 1；省奖档出现 Prophet 1。
- **适用条件**：观测等间隔、样本量足够定阶。
- **必备检验**：ADF 平稳性与差分阶数、AIC/BIC 定阶、残差白噪声、滚动预测误差。
- **常见坑**：非平稳序列直接拟合；周期性未处理；状态阈值无依据。

### 10. 决策与博弈
- **候选**：博弈论（纳什均衡、Stackelberg 主从博弈）、多准则决策、贝叶斯决策、随机与鲁棒优化。
- **适用条件**：存在多主体或不确定性下的选择，需明确策略空间与收益函数。
- **必备检验**：均衡存在性与唯一性、收益参数灵敏度、与单主体最优方案对比。
- **常见坑**：把单目标优化包装成博弈；收益矩阵参数无来源。

## 四、组合建模的常见结构

- **评价 + 优化**：先用评价模型定权重或优先级，再进优化模型求解方案。
- **预测 + 优化**：先预测需求或价格，再据此规划；必须做预测误差对最优解的灵敏度。
- **机理 + 数据**：机理给方程骨架、数据辨识参数；必须写参数可辨识性与残差。
- **降维/聚类 + 回归或分类**：先降维或分群再建模；必须说明信息损失。
- **仿真 + 优化**：仿真评估方案、启发式搜索方案空间；必须说明搜索次数与收敛情况。

组合建模必须在论文里写清“哪一步解决哪一问、模块之间怎么衔接”，避免各问方法论堆砌而无衔接。

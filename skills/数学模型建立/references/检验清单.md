# 检验清单

方案里必须逐项回答“做了没有 + 结果 + 结论”。确实不适用的写“不适用 + 理由”，不得整节留空。检验不通过时，要么修正模型，要么在“模型局限”里明确写出影响。

## 一、通用检验（所有题必做）

| 环节 | 检查项 |
|---|---|
| 数据 | 缺失率与处理方式、重复记录、异常值识别（IQR 或 3σ）、量纲与单位一致性、时间/空间对齐、口径一致性 |
| 假设 | 每条假设写出依据与可检验性；能检验的必须检验（如正态性、独立性、平稳性） |
| 模型 | 量纲齐次性、参数可辨识性、边界与极端条件行为、与题目约束是否冲突 |
| 结果 | 数值合理性（与文献/常识量级对比）、对题给红线（指定时刻/指标/格式）的满足情况 |
| 稳健性 | 参数扰动（±5%/±10%）、数据扰动（去极值、子样本）、方法替换（换同类模型）三选二以上 |

## 二、按模型类型的必做检验

| 模型类型 | 必做检验 |
|---|---|
| 评价/排序（AHP、熵权、TOPSIS、模糊综合、灰色关联） | 权重敏感性（权重 ±10% 排序是否翻转）、AHP 一致性 CR<0.1、多权重法对比（主观/客观）、排序稳定性（Spearman 秩相关） |
| 预测（回归、ARIMA、灰色、神经网络） | 误差指标（RMSE/MAE/MAPE）、残差白噪声检验、滚动/留出交叉验证、外推风险说明、灰色模型级比检验与后验差比 |
| 优化（线性/整数/非线性/多目标/启发式） | 可行性与约束满足、最优性或 gap、参数灵敏度、多起点或多次运行稳定性、与贪心/基准方案对比 |
| 机理/微分方程（含物理建模） | 参数辨识可行性、量纲分析、平衡点与稳定性、数值稳定性与步长敏感性、与实测残差 |
| 统计推断（回归、方差分析、假设检验） | 多重共线性 VIF、异方差、自相关 DW、显著性、模型选择（AIC/BIC）、变量选择稳定性 |
| 分类/聚类（逻辑回归、决策树、SVM、K-means、因子/主成分） | 聚类数或超参选择依据（肘部/轮廓系数/交叉验证）、类别不平衡处理、混淆矩阵或轮廓系数、降维后累计方差贡献 |
| 图论与网络（最短路、网络流、匹配） | 连通性、解的可行性校验、复杂度与规模上限、与枚举小规模最优解对照 |
| 仿真（Monte Carlo、元胞自动机、排队论） | 收敛性（重复次数与标准误）、置信区间、随机种子记录、与解析解或极限情形对照 |
| 时间序列与状态转移（ARMA、马尔可夫） | 平稳性与阶数定阶（ADF、AIC/BIC）、残差检验、状态划分依据 |

## 三、灵敏度与稳健性写法

- 明确扰动对象（参数、权重、数据子集）、扰动幅度、观察指标（结论量、排序、误差）。
- 给出结果表：扰动前后关键量对照与结论是否改变。
- 结论改变时，说明临界阈值（多大扰动会翻转结论）——这是论文里的加分点。

## 四、模型对比与择优

- 至少与一个更简单的基准方法对比（如均值/线性/贪心/单一指标排序）。
- 对比维度固定为：拟合或误差指标、可解释性、数据需求、计算成本、对结论的稳健性。
- 采用更复杂模型时给出理由；本地选型库里没有的新方法尤其要说明为什么它更合适（并挂出处）。

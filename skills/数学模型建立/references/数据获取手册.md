# 数据获取手册

题目需要外部数据时按本手册执行：先找权威源，再下载落地，再清洗，最后交用户确认。

## 一、来源优先级

1. **官方统计与政府开放数据**：国家统计局（data.stats.gov.cn）、各部委与统计局公开数据、省市开放数据平台、世界银行/联合国/OECD/IMF、各国统计局。口径可追溯，优先作为 A 级数据来源。
2. **科研数据集**：UCI Machine Learning Repository、Kaggle、Zenodo、Figshare、Dryad、天池、Papers with Code 附带数据。使用前确认许可与版本。
3. **遥感与地理数据**：NASA Earthdata、USGS EarthExplorer、Copernicus/Sentinel、地理国情与行政区划标准数据。注意坐标系统与分辨率口径。
4. **行业与企业数据**：上市公司年报与招股书、行业协会年度报告、官方统计公报。仅用公开披露口径。
5. **文献附带数据**：论文补充材料、图表数据、复现包。引用时必须给出原文出处。
6. **代码仓库数据**：GitHub 上同题仓库的中间数据集，仅作交叉验证，不作唯一来源。

## 二、抓取合规

- 遵守 robots.txt 与站点条款，不绕过登录、付费墙、验证码。
- 单站点限速（默认 ≥1 秒/请求，批量任务 ≤200 请求/次），使用明确 User-Agent。
- 不采集个人隐私数据、不抓取明令禁止转载的内容；数据许可（CC、ODbL、政府开放许可）记进数据文档。
- 下载失败（403/429/超时）先降速重试一次，仍失败则换源并在文档中记录失败原因。

## 三、下载与登记

统一用 `scripts/fetch_data.py`：

```
<MODELING_PY> scripts/fetch_data.py --url "<URL>" --out "<交付目录>\data\raw" --source "<机构/站点>" --note "<口径说明>"
```

每次下载都会在 `data\sources.csv` 追加一行：文件、URL、来源、抓取时间、HTTP 状态、字节数、sha256、备注。原始文件**只增不改**，清洗结果写到 `data\clean\`。

## 四、降级路径（取不到数据时按序尝试）

1. 换同口径的权威源（例如从省级统计局换到国家统计局分省数据）。
2. 用官方汇总口径反推（增长率、指数、占比），并在文档中说明换算公式与误差。
3. 用文献中公开的数据（必须 A/B 级来源，记录页码与年份）。
4. 参数化处理：把缺失量设为参数，给出区间并做灵敏度分析，明确告知用户“该量由假设给出，不是实测数据”。
5. 仍不可得：在方案与数据文档中显著标注数据缺口及其对结论的影响，不得用编造或来源不明数据填补。

## 五、常见坑

- **单位与口径**：同一指标不同年份可能改口径（如不变价/现价、常住/户籍），必须记录口径与换算。
- **缺失编码**：`-999`、`...`、空串、`N/A` 等要统一识别为缺失，不要当数值参与计算。
- **时间对齐**：日/月/年频率不一致时明确重采样方式（求和/均值/期末值）。
- **地区编码**：行政区划代码随年份变更，需按当年标准表对齐。
- **重复与修订**：官方数据常有修订版，记录使用的版本与下载日期。

## 六、国际数据源清单（含本机实测可达性，2026-09-10）

| 来源 | 入口 | 典型用途 | 实测 |
|---|---|---|---|
| World Bank Open Data | `data.worldbank.org`；API `api.worldbank.org/v2/country/<ISO>/indicator/<CODE>?format=json` | 各国宏观与发展指标 | 可达 |
| UN Data | `data.un.org` | 全球人口、能源、贸易等 | 可达 |
| OECD Statistics | `stats.oecd.org` | 发达国家经济与社会指标 | 可达 |
| Eurostat | `ec.europa.eu/eurostat` | 欧盟区域统计 | 可达 |
| US Census Bureau | `census.gov` | 美国人口与经济 | 可达 |
| WHO | `who.int` | 卫生与疾病数据 | 可达 |
| Our World in Data | `ourworldindata.org` | 已整理数据集（附原始出处，便于溯源） | 可达 |
| UCI ML Repository | `archive.ics.uci.edu` | 经典建模数据集 | 可达 |
| Kaggle | `kaggle.com` | 竞赛数据集（必须核验许可与原始出处） | 可达 |
| OSF | `osf.io` | 研究复现数据 | 可达 |
| IMF / FRED / BLS / Zenodo / SSRN | `imf.org`、`fred.stlouisfed.org`、`bls.gov`、`zenodo.org`、`ssrn.com` | 经济金融与预印本 | 本机不可达；改用世行/OECD 同口径数据或换镜像 |

- 世行 API 取数示例：`https://api.worldbank.org/v2/country/CHN/indicator/NY.GDP.MKTP.CD?format=json&per_page=100`
- **口径差异必须在数据文档中写明**：国际数据与国内统计对同一指标的定义常不同（就业、通胀、城镇化等），跨源使用要给出口径说明与换算方式，必要时只作趋势对照而不做绝对量比较。
- **国际数据检索同样走双线**：中文关键词（如“城镇居民人均可支配收入”）与英文关键词（`urban household disposable income`）分别检索，取权威度更高、口径更接近题意的一方。

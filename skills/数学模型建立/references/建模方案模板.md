# 建模方案文档模板（01_建模方案_模型与公式.md）

按下列章节顺序写作，标题可微调，但**内容不得缺项**。公式用 LaTeX，编号形如 `(1)`、`(2)` 且连续；参考文献用 GB/T 7714 尾注。

## 1. 题目理解与问题拆解
- **数学问题定义（本节第一项，必写）**：一句话数学问题陈述 + 对象与符号表 + 问题类型 + 数据在模型中的角色 + 可解性结论；写法见 `数学化理解题意.md`。
- **数据需求清单（必写）**：待获取量 × 口径/粒度/时间空间范围/精度/用途/来源，是取数与门禁一的验收标准。
- 年份题号、题目背景一句话概括、已知条件与附件清单。
- **问项卡**：逐问列出「要建什么模型 / 需要什么数据 / 必须给出什么（数值·表·文件）/ 红线」。
- 总体建模思路图（Mermaid flowchart，含数据流与模型流）。

## 2. 模型假设与符号说明
- 假设逐条编号，每条写依据；能检验的注明在第 6 节对应检验项。
- 符号表：符号、含义、单位、取值范围（与题意一致，不自造冲突符号）。

## 3. 数据与预处理方案
- 需要哪些数据、从何而来（引用数据文档与来源编号）、口径与单位。
- 预处理步骤：缺失、异常、标准化、降维、特征构造；每步给出方法依据。
- 若本题不依赖外部数据，这里写“数据来源为题给附件/公开统计数据”，并说明口径。

## 4. 候选路线对比与选型
- 2–4 条完整路线，逐条给出：核心模型、数据需求、可检验性、计算成本、创新性、风险。
- 对比表 + 选型结论 + 理由；**联网发现更合适的方法时，写出为什么它优于本地常见做法（挂来源）**。

## 5. 逐问模型建立
每问固定小节，包含：
1. 问题重述与建模目标（量化表述）。
2. 模型选择理由（1–2 句，挂来源）。
3. 完整公式：目标函数、约束、状态方程、评价函数等，逐个编号；变量含义当场说明。
4. 参数取值与来源（题给 / 文献 / 估计，分别标注）。
5. 求解思路：算法流程（文字步骤 + 可选 Mermaid）、工具建议、复杂度与规模估计。
6. 本问的检验项（指向第 6 节清单条目）。
7. 预期输出：题面要求的数值、表格、文件格式与命名。

## 6. 检验与灵敏度分析方案
- 按 `检验清单.md` 逐项列出「本项目做/不做 + 做法 + 判据 + 不通过时的处理」。
- 灵敏度设计：扰动对象、幅度、观察指标、预期临界阈值。
- 灵敏度结果用**图**表达时，图必须由 Python 脚本生成：给出数据文件、图表定义与生成脚本路径，数值标注由脚本按数据生成（不得手工改图）；表格一律用原生表格。
- 模型对比：与基准方法的对比指标。

## 7. 模型优缺点与适用边界
- 优点、局限、适用范围、外推风险，各 2–4 条，具体到本模型而非套话。

## 8. 论文章节映射
- 表格：本方案章节 → 对应国赛论文章节（摘要要点、问题重述、模型假设、符号说明、模型建立与求解、检验、模型评价、参考文献）。
- 摘要要点：3–6 句，含用了什么模型、怎么求解、得到什么结论。
- 图表清单：每问计划出的表与图（图题、表题写法建议），并注明每张图的生成脚本与数据文件，以及每张表的字段与单位。

## 9. 参考文献（尾注）
按 GB/T 7714 编号列出，与正文一一对应。

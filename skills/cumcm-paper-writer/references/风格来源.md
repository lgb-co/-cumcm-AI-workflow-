## gexiangyu0608/cumcm-paper-writing.skill

- 来源：https://raw.githubusercontent.com/gexiangyu0608/cumcm-paper-writing.skill/main/README.md
- 仓库自述：# CUMCM 论文写作 Skill /  / 这是一个面向全国大学生数学建模竞赛的 Agent Skill，用于完成中文论文写作、修改、LaTeX 排版和终稿检查。 /  / 它遵循以 `SKILL.md` 为入口的 Agent Skills 目录结构，可由 OpenCode、Codex 及其他支持该结构的 Agent 加载。Skill 可以根据题目、数据、程序、图表和已经验证的建模结果创建论文，也可以继续修改

**可借鉴条目**

  - **OpenCode**：原生支持 `SKILL.md`，通过内置 `skill` 工具按需加载。
  - **Codex**：可原生发现并调用 Skill，`agents/openai.yaml` 提供额外的界面元数据。
  - **其他 Agent**：支持 Agent Skills 或 `SKILL.md` 的客户端可以放入其 Skill 目录；不支持自动发现时，也可以让 Agent 先完整读取 `SKILL.md` 再执行。
  - 竞赛题目或题目 PDF
  - 原始数据和字段说明
  - 已完成的模型、算法与求解流程
  - 可以复现的程序代码
  - 已验证的数值结果和评价指标
  - 图表、图片及其数据来源
  - 需要保留的已有论文或 LaTeX 工程
  - 学校或指导教师的额外格式要求
  - `paper.tex`：论文正文入口

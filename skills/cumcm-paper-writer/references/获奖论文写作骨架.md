# 获奖论文写作骨架（数据集 444 篇实证）

> **主证据源**：`数据集/`——按年份与奖项分层的真实获奖论文（全国一等/二等、省一等/二等、优秀论文，及按算法归档的获奖论文）。论文文件 544 篇，有效正文 ≥2000 汉字的 **444 篇**。
> **交叉核对源**：`训练语料/papers_text/`（243 篇，有效 177 篇），同口径重算，结论一致。
> 统计日期 2026-09-11。
> 复现：`工具\ocr_env\Scripts\python.exe 工具\dataset_style_stats.py`（主源；明细见 `数据集风格统计.md` 与 `数据集风格统计_逐篇.csv`，文本缓存 `工具/_cache/dataset_text/`）；风格基线 `scripts/mine_style_baseline.py --corpus 工具/_cache/dataset_text_named` → `风格基线_数据集.json`。
> 用途：论文写作的**结构模板与风格锚点**；与 `风格基线_数据集.json`（14 项密度指标）配套使用。

## 一、章节骨架（出现率）

| 章节 | 数据集提及率 | 数据集成节率 | 交叉源成节率 | 说明 |
|---|---|---|---|---|
| 参考文献 | 95.0% | 68.0% | 79.1% | 必备 |
| 模型建立 | 91.2% | 59.0% | 68.4% | 常与求解合并为一节 |
| 问题重述 | 85.6% | 61.0% | 75.7% | 用自己的语言压缩，不整段抄题 |
| 问题分析 | 77.0% | 59.9% | 71.2% | 逐问给思路与路线，别只写"本题很重要" |
| 符号说明 | 75.5% | 55.2% | 66.1% | 先写命名约定，再给三线表 |
| 模型假设 | 75.0% | 57.0% | 71.2% | 逐条编号 + 依据 |
| 附录 | 71.4% | 45.0% | 55.9% | 必备（国赛还要求含全部源码） |
| 模型评价 | 61.0% | 29.7% | 33.3% | 优点/缺点多为小节，放在全文末尾 |
| 模型检验/误差分析 | 32.0% | 8.8% | 15.8% | 常写作"误差分析""结果分析" |
| 灵敏度/稳健性 | 26.4% | 3.8% | 10.2% | 高奖论文显著更多 |

> 口径：**提及率**＝全文出现该节相关表述；**单列成节率**＝该节名独立成行（行首，可带编号）；交叉源＝`训练语料` 177 篇同口径复算。两个数据源的方向一致（数据集偏低是因为它收录了更多省奖与早期论文）。

节标题频次（数据集，按出现文件数）：参考文献 188、模型假设 160、问题分析 124、问题重述 111、模型建立 85、模型求解 70、**问题二的分析 67**、**问题三的分析 66**、**结果分析 65**、**模型的推广 59**、**模型的缺点 57**、附录 52、模型的建立与求解 48、问题四的分析 46、符号说明 41——主流写法是"逐问分析小节 + 末尾优点/缺点/推广"。

结论：**标准骨架必须有；检验、灵敏度、推广是拉开档位的地方**，本技能一律要求写全。

## 二、摘要规格

- 中文字数（数据集）：中位 **760**，均值 722，p25–p75＝559–918（n=380，范围 72–2118）；交叉源中位 831（688–973）→ 目标 **600–1000 字**。
- 结构：背景一句 → 逐问"方法+关键结论（带数字）" → 特色/边界。
- 关键词：中位 **4** 个（3–5 个为宜）。

## 三、逐问推进（常规写法，不是 AI 味）

| 表述 | 出现率 |
|---|---|
| "问题一/二/三" | 65–67% |
| "针对问题一/二/三" | 30–34% |
| "如图" / "如表" | 59% / 30% |

要求：每问写成"模型 → 求解 → 结果（带数）→ 检验"，并在正文引用对应图表编号。

## 四、哪些词不是 AI 特征（勿错杀）

| 表述 | 出现率 |
|---|---|
| 本文 | 80% |
| 首先 | 79% |
| 我们 | 76% |
| 最后 | 72% |
| 其次 | 38% |
| 综上所述 | 31% |
| 结果表明 | 20% |

**判定口径**：不看"有没有用"，看**密度与分布**——连接词密度 0.32–0.88/千字、人称 1.03–3.41/千字、相邻段首重复率 0.03–0.12、超长句占比 0.32–0.47、含数字句占比 0.47–0.62（数据集 442 篇，详见 `风格基线_数据集.json`）。

## 五、写作红线（与格式规范同级）

1. 骨架完整、每问闭环；检验/灵敏度/推广必须写。
2. 摘要 600–1000 字，关键词 3–5 个；摘要数字与正文一致。
3. 正文不得出现任何 Markdown 残留（`**`、`##`、`|---|`、`$$`、`\tag{}`、`![`、反引号）。
4. 风格指标用密度口径卡（`check_paper_style.py`），不得用"禁用词表"。

## 六、编号层级与逐问展开（数据集实证）

- **94.4%** 用小数编号标题；**72.3%** 有二级标题（`1.1`）；**60.4%** 用到三级标题（`1.1.1`）；交叉源同向（98.3% / 87.0% / 73.4%）。
- 常见开头：`问题重述`（其中 `1 问题背景` / `2 问题提出`）→ `问题分析` → `模型假设`。
- 主文骨架（推荐直接采用）：

```text
1 问题重述        1.1 问题背景   1.2 问题提出（或 问题要求）
2 问题分析        2.1 总体思路   2.2 问题一分析  2.3 问题二分析 …
3 模型假设        （逐条编号 + 依据）
4 符号说明        4.1 符号约定（命名与上下标规则，2–4 句）  4.2 符号表（符号/含义/单位）
5 模型建立与求解
   5.1 问题一
       5.1.1 模型描述（面向本问的对象、变量与目标）
       5.1.2 模型建立（完整公式，编号 (1)(2)…）
       5.1.3 模型求解（算法步骤、参数取值、结果）
       5.1.4 结果分析（结果 + 检验 + 边界，3–5 段；标题可用"结果分析/误差分析"）
   5.2 问题二 ……（同构）
6 模型检验与灵敏度分析（误差、守恒、网格/步长、参数灵敏度、模型对比）
7 模型的评价与推广（优点 / 局限 / 适用边界 / 推广方向）
参考文献（GB/T 7714 顺序编码制）
附录（支撑材料文件列表 + 全部完整源码）
```

- 每问必须"闭环"：模型描述 → 公式 → 求解 → 结果（带数字）→ 收束段；**过程与结论分开写**，不要把所有结果堆到最后。
- 收束段的写法：以"结果分析/误差分析"标题或直接以收束段收尾（数据集中"结果分析"标题 32.9%）。"小结"字样仅 0.2%、独立"模型总结"章 1.1%——**内容要闭环，标题不必强加**。
- 全文用第 7 章《模型的评价与推广》收束（数据集中"模型的缺点/优点"与"模型的推广"是常见收尾小节），并保持"检验/灵敏度/推广"齐全，这是高奖论文的差异化区。

## 七、符号说明的规则（55.2% 的论文单列此节；交叉源 66.1%）

1. **先约定后列表**：先用 2–4 句写命名规则（例：标量用斜体拉丁字母、向量用粗体、矩阵用大写、浓度类量统一用 $C$、下标 $r$ 表示径向偏导），再给符号表。
2. **符号表三列**：符号 / 含义 / 单位；用三线表（Word 原生表格），不要截图。
3. **排序**：按正文首次出现顺序排列，不按字母表。
4. **一致性**：同一对象全篇一个符号；上下标含义固定；符号表中的单位与控制方程量纲一致。
5. 符号不在正文即删；正文出现而未列表即补——交付前用 `check_paper.py` 与人工各扫一遍。

## 八、公式的写法：学术感的来源（数据集 444 篇复算）

真实论文的推导链是**连着的**，不是把公式摆出来就完事。复算统计：显式写出代入/联立衔接 **68.9%**，用"其中，… 为 …"逐符号解释 **63.1%**（另有 32.4% 用"式中，"），用"即/可得"收束 **90.1%**，分步推导序号 19.1%。每处公式都按下面五拍写：

1. **文字引入**：先说这一步要刻画的机制与为什么要它（"水分在浓度梯度驱动下向表面迁移，由质量守恒有…"）。
2. **列式并编号**：公式单独成行、右端编号 `(1)(2)…`，编号在正文被引用。
3. **逐符号解释**：紧跟"其中，$C$ 为湿基含水率（kg/kg），$D$ 为有效扩散系数（m²/s）…"，单位与符号表一致。
4. **推导衔接**：显式说明从哪一步到哪一步——"将式(3)代入式(2)并整理得…""对式(5)沿半径积分，得…"；不跳步、不突然出现未定义符号。
5. **收束与解读**：用"即…""由此可得…"收口，再补一句物理意义或量级判断（如"该式表明干燥时间与半径平方成正比"）。

配套两条：

- **假设要"用得上"**：每条模型假设编号并注明依据，且必须在后文某个方程里被真正使用（数据集中模型假设单列成节 57.0%；假设与推导脱节是最常见的失分点）。
- **过程与结果分开**：推导段落只讲怎么来的，结果、误差与边界放到该问收束段，避免"推导一句、结论一句"来回跳。

## 九、段落推进节奏：模型是什么 → 公式怎么样 → 本题怎么用

获奖论文读起来"学术"，靠的不是辞藻，而是每段的推进顺序固定为四拍：

1. **这个模型/方法是什么**：先交代它的思想、适用条件与要刻画的对象（"设油位高度为 $h$，储油罐截面为椭圆，由几何关系…"）。
2. **公式长什么样**：给出一般形式并编号，逐符号解释（见第八节五拍）。
3. **本题怎么用**：说明本题的参数取值、数据来源、代入与算法步骤（"取 $\alpha=2.16°$、$\beta=4.50°$，代入式(7)计算得到罐容表"）。
4. **得到什么、意味着什么**：结果落在具体量上，并回扣问题（预测值、决策建议、误差范围）。

数据集实证：**94.4%** 的论文最终落到"预测/决策/建议/推广"这类回扣问题的表述，**50.7%** 明确写出参数估计或标定过程，**40.1%** 明确交代模型的思想/原理；"式(1) 即为…模型""根据此模型…"这类显式衔接各约 12–14%（多数论文用更自然的说法完成同样的事，不必照抄句式）。

实例（2010 A 全国一等奖，原文）：

> …两种方法得到的体积公式完全等价，(1)式即为小椭圆储油罐无变位时的储油量和油位高度关系的模型。根据此模型，我们可以求出小椭圆储油罐无变位时罐容表标定值…

## 十、骨架是下限，不是上限

上面的章节是**默认模板**，按题目需要可以增删小节——真实获奖论文本来就各有增补：

| 常见增补小节 | 适用场合 |
|---|---|
| 数据来源与预处理 | 给了附件数据、需要清洗/插值/筛选 |
| 参数估计与标定 | 模型参数要从数据反推（数据集中 50.7% 明确写） |
| 算法设计与流程 | 启发式/数值算法，需要给伪代码与复杂度 |
| 模型对比与选型 | 有多个候选路线，需说明为什么选它 |
| 误差分析与灵敏度分析 | 结果对参数敏感、或需要给出置信区间 |
| 模型的优缺点与推广 | 全文收尾（"模型的缺点/优点" "模型的推广"是高频小节） |

约束只有三条：**七章要素齐全**（问题重述 / 问题分析 / 模型假设 / 符号说明 / 模型建立与求解 / 模型检验 / 模型评价与推广）、**每问闭环**、**数字与图表可追溯**。题目简单就写紧，题目复杂就展开；不要为了填骨架而堆无内容的章节，也不要为了精简而砍掉检验与评价。

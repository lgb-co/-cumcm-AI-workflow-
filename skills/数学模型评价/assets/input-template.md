# 建模方案评价输入

## 必交材料

- 报告保存路径：必须由使用者指定；Skill 会在此路径下创建 `数学模型评价` 文件夹。
- 完整赛题：文件名；年份/组别/题号（未知可留空）。
- 题目列出的附件清单：逐个文件名及对应要求；若无附件，引用原题依据。
- 当前方案：上传文件，或按以下格式填写每一问。未完成的环节写“未设计”。

## 第 __ 问

- 本问目标与必须输出：
- 使用数据、字段和单位：
- 模型名称、具体变体及选择理由：
- 主要假设、变量、目标函数、约束或方程：
- 求解算法名称与步骤（含预处理、参数选择、停止条件）：
- 输入如何变成输出；与其他小问如何衔接：
- 验证、基线、敏感性或稳健性计划：
- 自称改进的部分及已有依据（若有）：

无需提供完整论文、程序或计算结果。已有结果可作为补充，不是收件条件。模板中的方案细节为空会成为诊断内容；缺赛题或题目必要附件则需先补齐。

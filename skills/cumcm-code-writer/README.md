# 代码编写 · 数模代码编写 Skill

> 面向数学建模竞赛的**代码生成**技能：用户给出「模型＋算法＋框架（可选赛题与论文提纲）」，技能先把数据与本机工具凑齐，再按竞赛可读风格写代码，三轮自测通过后产出**附录文档**与**结果文档**。
> 本技能是 `代码编写评价/`（评审向）的写作向对偶：一个查代码，一个写代码。

## 目录

| 路径 | 内容 |
|---|---|
| `SKILL.md` | 触发条件、硬门禁 G0–G3、五阶段流程、输出规范 |
| `references/` | 风格与规范：算法-模型对照表、代码风格、低 AI 味、数据交接、环境检查、可视化、文档规范 |
| `references/algorithm_library/` | 精选参考代码库：90 个算法 / 180 个模板 + 元数据 + 方法依据 |
| `scripts/` | 环境检查/引导、数据校验、参考库抓取与构建、三轮自测、附录与结果文档生成、安装脚本 |
| `templates/` | 附录、结果报告、数据说明、参考依据、论文口径模板，以及项目骨架（含 Python 绘图助手 `plotting.py`） |
| `work/<项目名>/` | 单次任务的中间产物（清洗数据、图源、自测日志） |
| `output/<项目名>/` | 单次任务的交付物（代码、两份文档、图表） |

## 快速使用

1. 在 Codex 里说明模型、算法、框架，并附上数据文件（或明确说明无需数据）。
2. 技能先跑环境与数据门禁；缺什么会给你一份待补清单，不会直接写代码。
3. 门禁通过后生成代码，写 `work/<项目名>/参考依据.md` 记录命中模板与偏离并登记 `论文口径.md`，三轮自测留痕，最后跑 `scripts/check_gates.py` 七项全绿才交付附录与结果文档。

## 边界

- 只写代码与两份文档，不写论文正文，不给奖项位次。
- 产物只落在本工作区内，不改写 `数据集/`。
- 参考库只收录宽松许可（MIT/BSD/Apache/CC0）实现；GPL 类只登记不复制。
- 本技能放在工作区内，Codex 不会自动发现；需要全局使用时运行 `scripts/install_skill.ps1`。

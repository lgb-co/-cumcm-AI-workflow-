# 环境与工具检查规范

> 用途：写码前确认“这台机器能不能跑起来”。工具不齐就先补齐，不做“先写完再说”的赌博。

## 一、探测项

| 类别 | 探测内容 | 判定 |
|---|---|---|
| Python | 解释器路径、版本（要求 ≥3.10） | 无可用解释器 → 报告并请求安装 |
| Python 包 | 本题需要的包是否可导入、版本号 | 缺包 → 走 `bootstrap_env.py` 装进工作区虚拟环境 |
| Python 绘图环境 | numpy、matplotlib 是否可导入；`CODE_ENV_PYTHON` 是否可用 | **强制项**：缺则停止并请用户安装 Python 3.10+ |
| MATLAB | `matlab` 可执行文件、版本、已装工具箱 | 缺 MATLAB 或工具箱 → 报告并给替代方案 |
| 中文字体 | SimHei / Microsoft YaHei / SimSun 是否可被 matplotlib 找到 | 缺字体 → 报告，绘图前先修字体 |
| 磁盘 | 工作区所在盘剩余空间（建议 ≥5 GB） | 不足 → 提示清理 |
| 外部求解器 | 若用到 CBC/Gurobi/IPOPT 等，探测可执行文件与许可 | 不可用 → 换开源求解器或说明 |

> 绘图环境是**交付硬要求**：所有交付图件由 Python 生成，MATLAB 只做计算。
> 缺失时输出给用户的操作指令：
>
> ```text
> 缺失项：可用 Python 解释器（含 numpy、matplotlib）
> 原因：交付图件必须由 Python 绘制
> 处理：安装 Python 3.10+（https://www.python.org/downloads/），然后运行
>       python scripts/bootstrap_env.py --install-optional
> ```

## 二、虚拟环境策略

- 统一使用工作区虚拟环境 `工具/code_env/`，不往系统 Python 装包。
- 该环境由 `工具/ocr_env/Scripts/python.exe -m venv 工具/code_env` 创建，Python 3.12。
- 安装命令固定为：

  ```powershell
  & "<你的工作区>\工具\code_env\Scripts\python.exe" -m pip install <包名>
  ```

- 每个项目在 `code/requirements.txt` 里记录实际用到的包与版本，便于复现。

## 三、解释器定位与跨机迁移

- 脚本按固定顺序定位 Python：环境变量 `CUMCM_CODE_ENV` → 工作区 `工具/code_env/Scripts/python.exe` → 当前解释器。
- 把技能复制到别的机器时，只要设置 `CUMCM_CODE_ENV` 指向该机的虚拟环境目录（或直接指向 `python.exe`），所有脚本即可复用，不必改代码。
- MATLAB 侧不支持路径覆盖，统一通过 `matlab -batch` 调用；换机后先用 `matlab -batch "ver"` 核对工具箱清单。

## 四、包分层

| 层级 | 包 | 用途 |
|---|---|---|
| 核心（默认装） | numpy, scipy, pandas, matplotlib | 数值计算、数据处理、绘图 |
| 常用（按需装） | scikit-learn, statsmodels, seaborn, openpyxl, networkx, sympy, pulp, tqdm, joblib, pyyaml, imageio, python-docx | 机器学习、统计检验、网络优化、符号推导、线性规划、文档生成 |
| 可选（用到再说） | cvxpy（凸优化）、deap / pyswarms（进化与群智能）、plotly（交互图）、geopandas / shapely（空间数据）、pygam、pymoo（多目标） | 特定题型 |

不默认安装深度学习框架；需要神经网络时优先用 scikit-learn 的 MLP，若必须用 torch 等，先说明体积与用途并单独征求同意。

## 五、MATLAB 侧

- 已确认本机 MATLAB 位于 `D:\matlab\bin\matlab.exe`，含 `optim`、`stats`、`symbolic`、`econ` 工具箱。
- 无 Global Optimization Toolbox：GA/PSO/SA 这类用自写实现，不调用 `ga` / `particleswarm`。
- 无 Fuzzy Logic Toolbox：模糊综合评价用矩阵运算自写。
- 无 Deep Learning Toolbox：神经网络改用 `fitnet`/`patternnet` 之外的手段，或改走 Python。
- 运行 MATLAB 模板统一用批处理方式：`matlab -batch "run('main.m')"`，便于留痕。

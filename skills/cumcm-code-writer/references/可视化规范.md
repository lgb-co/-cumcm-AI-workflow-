# 可视化规范

> 目标：图要经得起评委追问——口径清楚、单位齐全、能复现；同时在规范之上留一张说得清“故事”的主图。
> 底线：**图里的每一个数字都要能由脚本重跑得到**。

## 零、硬性前提：图件由 Python 生成

- 所有交付图件（PNG 300dpi + 矢量 PDF）**必须用 Python + matplotlib 绘制**，MATLAB 只负责计算，
  不允许用 `exportgraphics` / `saveas` / `print -dpng` 出交付图。
- 因此本机必须存在可用的 Python 解释器与 numpy、matplotlib。缺失时**停下来让用户安装**
  （Python 3.10+：<https://www.python.org/downloads/>），再用 `scripts/bootstrap_env.py --install-optional` 补齐依赖，
  不要退化成 MATLAB 出图、也不要跳过出图。
- 绘图脚本与结果表分离：图的数据先落到 `tables/`，绘图代码单独成文件，便于复现与改风格。

## 一、统一样式

| 项目 | 规定 |
|---|---|
| 字体 | 中文用 SimHei 或 Microsoft YaHei，英文与数字用 Times New Roman / DejaVu Serif；负号显示正常（`axes.unicode_minus=False` 前先设好字体） |
| 分辨率 | PNG 300 dpi；同时导出 PDF 矢量图 |
| 尺寸 | 单栏图约 12×8 cm，双栏图约 16×10 cm；字号不小于 8 pt |
| 配色 | 色盲友好序列（如 Okabe-Ito、viridis、cividis）；同一含义全篇同色 |
| 坐标轴 | 必须有轴标签与单位；必要处加网格（浅灰、细线）；避免 3D 装饰与阴影 |
| 标注 | 关键点直接标数值或竖线标注，不用图例堆叠 |
| 图题 | 中文，格式统一为「图 x-y 标题（口径说明）」，编号与论文小节一致 |
| 表图一致 | 图的数据源文件与结果表同源，写在 `tables/` 与 `figures/*.csv` |

## 二、按问选图

| 问题类型 | 规范图 | 信息量更高的主图 |
|---|---|---|
| 评价排序 | 条形图（带数值标签） | 得分-权重组合图：堆叠条形 + 权重雷达/桑基 |
| 权重分析 | 权重条形图 | 权重敏感性热力图（权重×方案得分） |
| 时序预测 | 折线 + 真实值/预测值 + 置信带 | 分位数扇形图 + 残差子图 + 误差指标表注 |
| 优化结果 | 收敛曲线（含多算法对比） | 收敛曲线 + 解空间示意 + Pareto 前沿（多目标） |
| 空间/区域 | 分区着色图（有地理数据时） | 分区图 + 排名连线或气泡标注 |
| 分类聚类 | 散点（前两维）+ 轮廓/混淆矩阵 | 轮廓系数-簇数曲线 + 簇中心雷达 |
| 相关与机理 | 相关系数热力图 | 相关热力图 + 显著性与样本量注记 + 粒子轨迹（机理类） |
| 不确定性 | 箱线/小提琴图 | 分布密度 + 置信区间 + 敏感性 tornado 图 |

## 三、创意主图的做法

- 每问在规范图之外再交一张主图，要求：能独立说明这一问的结论、含两到三个子图、带注释性文字（阈值线、最优解位置、拐点）。
- 排版优先顺序：左右对齐的网格、统一轴范围便于比较、留白用于结论文字。
- 允许联网参考优秀图形设计（配色、版式、注释方式），但**数值与坐标轴口径必须来自本项目的计算**，不得套用别人的数据或结论。
- 不使用 3D 饼图、环形图堆叠、双 Y 轴混用等容易误读的形式；确需双轴时要在图题中说明。

## 四、绘图脚本要求

- 一个图一个函数，函数只负责画图，数据从 `tables/` 传入。
- 保存统一走 `save_fig(fig, name)`：输出 `figures/<name>.png`（300 dpi）与 `figures/<name>.pdf`。
- 绘图前显式设置字体与尺寸；不依赖默认样式，避免换机器后字体缺失。
- 图内数值与论文中引用的数值来自同一份结果文件。

## 五、自检清单

- [ ] 每个图都有轴标签与单位，图题含口径。
- [ ] 颜色含义全篇一致，灰度打印仍可区分。
- [ ] 无中文缺字方框，无负号显示异常。
- [ ] PNG 与 PDF 都已生成，PNG 分辨率 300 dpi。
- [ ] 关键结论在图上可见（最优解、阈值、拐点、置信区间）。
- [ ] 重跑脚本能得到同样的图（随机过程固定种子）。

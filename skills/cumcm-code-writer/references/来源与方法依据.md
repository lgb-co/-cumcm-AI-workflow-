1. 写码前在该表里查对应算法的方法依据，核对公式口径（例如 Moran's I 的权重矩阵定义、
   Erlang-C 的分母形式、CFL 条件的表达）。
2. 摘要片段存于 `references/_methods/<id>.md`，只作口径核对，不作为代码来源。
3. 参考实现本身见 `algorithm_library/`，其来源与许可记录在 `registry.csv`。

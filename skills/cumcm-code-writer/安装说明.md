# cumcm-code-writer 安装说明

面向全国大学生数学建模竞赛（CUMCM）的**代码编写**技能：给出「数学模型＋算法＋框架」与数据后，
技能先做硬门禁（数据是否齐全、本机工具是否可用），再写代码、跑三轮自测，最后产出两份交付物：
① 符合国赛附录要求的《附录》（支撑材料清单＋全部完整源码，逐文件哈希校对）；
② 《结果文档》（逐问结果表＋严谨且具创意的可视化＋运行说明与环境快照）。

---

## 一、环境要求

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows | 脚本为 PowerShell |
| Python | **必需**，3.10 及以上（推荐 3.12） | 交付图件必须由 Python 生成，MATLAB 只做计算 |

> **为什么 Python 是必需的**：本技能的所有交付图件（300dpi PNG + 矢量 PDF）都由 Python + matplotlib 绘制，
> MATLAB 只承担计算。若技能在运行时发现本机没有可用的 Python 环境，会**停下来让你先安装**，
> 而不是改用 MATLAB 出图或跳过出图。安装地址：<https://www.python.org/downloads/>（选 3.10 以上版本）。
| MATLAB | 可选 | 只有需要 `.m` 代码时才用；缺工具箱技能会如实报告，不会假装跑通 |

## 二、安装

### 方式 A：自带安装脚本（推荐）

1. 解压本压缩包，得到 `cumcm-code-writer/` 文件夹。
2. 在 PowerShell 执行（`<解压目录>` 换成实际路径）：

```powershell
powershell -ExecutionPolicy Bypass -File "<解压目录>\cumcm-code-writer\scripts\install_skill.ps1"
```

脚本会复制技能到 `%USERPROFILE%\.codex\skills\cumcm-code-writer`，探测本机 Python，
并写入 `环境配置.json`。若提示未找到可用环境，先装 Python 或用下面的引导脚本建环境，再执行：

```powershell
powershell -ExecutionPolicy Bypass -File "<解压目录>\cumcm-code-writer\scripts\install_skill.ps1" -Force
```

### 方式 B：手工复制

把 `cumcm-code-writer` 整个文件夹复制到 `%USERPROFILE%\.codex\skills\` 下即可。

## 三、装依赖（首次使用前）

技能需要 numpy / scipy / pandas / matplotlib / scikit-learn / statsmodels 等。
本机已有可跳过；否则用自带脚本创建独立环境（不改动系统 Python）：

```powershell
python "%USERPROFILE%\.codex\skills\cumcm-code-writer\scripts\bootstrap_env.py" --install-optional
```

## 四、指定 Python 环境

技能按以下顺序找解释器，命中即用：

1. 环境变量 `CUMCM_CODE_ENV`（指向虚拟环境目录或 `python.exe`）
2. `%USERPROFILE%\.codex\skills\cumcm-code-writer\环境配置.json` 中的 `code_env`
3. 技能目录下的 `工具/code_env`
4. 当前解释器

换机器或换 Python 时，改 `环境配置.json` 的 `code_env` 即可。

## 五、使用

**新开一个 Codex 任务**（技能清单在任务开始时加载），然后直接提要求，例如：

> 这题第二问用整数规划，数据在 `附件1.xlsx`，帮我写代码并出附录和结果文档

产物默认写到技能目录下的 `output/<项目名>/`。想写到自己的项目目录：

```powershell
setx CUMCM_CODE_PROJECT "D:\myproject"
```

之后产物写到 `<该目录>\output\` 与 `<该目录>\work\`。

## 六、包内容

| 路径 | 内容 |
|---|---|
| `SKILL.md` | 技能入口：触发条件、硬门禁 G0–G3、五阶段流程、七项交付门禁 |
| `references/` | 算法-模型对照表、代码风格、低 AI 味、数据交接、环境检查、可视化、附录与结果文档规范 |
| `references/algorithm_library/` | 90 个算法 / 180 个最小可运行模板（Python + MATLAB）、元数据、方法依据 |
| `scripts/` | 18 个脚本：门禁、三轮自测、附录与结果文档生成、代码体检、图件检查、论文口径核对 |
| `templates/` | 附录、结果文档、数据说明、参考依据、论文口径、项目骨架 |

## 七、卸载

删除 `%USERPROFILE%\.codex\skills\cumcm-code-writer` 即可，不涉及注册表或其它配置。

## 八、边界

- 只写代码与两份文档，不写论文正文，不给奖项位次。
- 图件一律由 Python 生成，MATLAB 只负责计算；没有 Python 时技能会先让你安装。
- 参考实现为自写重写；第三方许可原文见 `references/algorithm_library/_vendors/licenses/`。
- 模板已在 Python 3.12 + MATLAB（optim/stats/symbolic/econ）下跑通；换机器后建议先跑 `scripts/check_env.py` 核对。
